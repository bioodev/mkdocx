# mkdocx Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** CLI Go `mkdocx` (Markdown→docx y plantilla+JSON→docx) más un `SKILL.md` para agentes.

**Architecture:** goldmark parsea Markdown a un modelo de bloques propio (`internal/md`); `internal/render` es el único paquete que importa docxgo y traduce el modelo a un documento; `internal/fill` envuelve `pkg/template` de docxgo; `cmd/mkdocx` solo parsea flags y despacha.

**Tech Stack:** Go 1.27 (`~/.local/go/bin` en PATH), `github.com/mmonterroca/docxgo/v2 v2.14.0`, `github.com/yuin/goldmark` (+ extensión GFM tablas), stdlib `flag`, `archive/zip`, `encoding/xml`.

**Spec:** `docs/superpowers/specs/2026-10-08-mkdocx-design.md`

## Global Constraints
- Módulo: `github.com/bioodev/mkdocx`; binario `mkdocx`; `CGO_ENABLED=0`.
- Solo dependencias: docxgo v2.14.0 y goldmark. Sin cobra.
- Solo `internal/render` y `internal/fill` importan docxgo.
- `-` significa stdin/stdout. Con `-o` archivo, stdout imprime solo la ruta de salida.
- Errores: una línea en stderr; exit 1 = uso/entrada, exit 2 = fallo de generación.
- Si el binario supera 10 MB, detenerse y reportar (reabre la decisión de dependencias).
- Limitación documentada: docxgo no tiene numeración real; las listas usan `ListParagraph` + prefijo literal (`• ` / `1. `) + sangría.
- Plantillas: solo `{{clave}}` / `{{a.b}}` planas (MergeData es `map[string]string`); sin bucles.

## Review Focus
- Markdown vacío o solo espacios → docx válido con un párrafo vacío, no error.
- Imagen inexistente o ruta relativa → ruta relativa al `.md`; archivo faltante da error claro (exit 1) con la ruta, sin docx parcial.
- Texto con caracteres XML (`< > &`), acentos, emoji → sobreviven intactos en el docx.
- Tabla con filas de distinto número de celdas → se rellena sin pánico.
- `fill` con JSON anidado/valores no string (números, bool) → se aplanan a `a.b` y se convierten a string.
- Salida a un directorio inexistente o sin permisos → error claro, sin pánico.
- Archivo de entrada inexistente → exit 1 y mensaje con la ruta.
- Lista anidada a 3+ niveles y listas mezcladas ordenada/no ordenada.

### Task 2: Modelo y parser Markdown (`internal/md`)

**Files:** Create `internal/md/model.go`, `internal/md/parse.go`; Test `internal/md/parse_test.go`

**Produces:**
```go
type Inline struct{ Text string; Bold, Italic, Code bool; URL string }
type Block interface{ isBlock() }
type Heading struct{ Level int; Inlines []Inline }
type Paragraph struct{ Inlines []Inline }
type ListItem struct{ Inlines []Inline; Children *List }
type List struct{ Ordered bool; Items []ListItem }
type CodeBlock struct{ Text string }
type Quote struct{ Inlines []Inline }
type Table struct{ Header [][]Inline; Rows [][][]Inline }
type Image struct{ Path, Alt string }
type PageBreak struct{}
func Parse(src []byte) ([]Block, error)
```

- [ ] **Step 1: Test que falla** (`parse_test.go`): tabla de casos `{md string, want []Block}` para: `# T` → `Heading{1,[{Text:"T"}]}`; `a **b** *c* \`d\`` → runs con Bold/Italic/Code; lista anidada; `[x](http://u)` → Inline con URL; tabla GFM; `![alt](p.png)` → Image; `<!-- pagebreak -->` → PageBreak; entrada vacía → `[]Block{}` sin error; `a < b & c` → texto literal intacto. Usar `reflect.DeepEqual`.
- [ ] **Step 2:** `go test ./internal/md/` → FAIL (undefined Parse).
- [ ] **Step 3: Implementar** `Parse`: `goldmark.New(goldmark.WithExtensions(extension.Table), goldmark.WithParserOptions(...)).Parser().Parse(text.NewReader(src))`; recorrer el AST con `ast.Walk`/hijos: `ast.Heading`, `ast.Paragraph`/`ast.TextBlock`, `ast.List`/`ast.ListItem`, `ast.FencedCodeBlock`/`ast.CodeBlock` (concatenar `Lines()`), `ast.Blockquote`, `extast.Table` (header = `TableHeader`, filas = `TableRow`, celdas = `TableCell`), `ast.HTMLBlock` cuyo texto trimmed == `<!-- pagebreak -->` → `PageBreak`, imagen única en párrafo → `Image`. Inlines: recursión sobre `ast.Emphasis` (Level 2 = Bold, 1 = Italic acumulando), `ast.CodeSpan`, `ast.Link`, `ast.Text` (+ `SoftLineBreak` → espacio, `HardLineBreak` → `\n`), `ast.String`. Helper `inlines(n ast.Node, src []byte, style Inline) []Inline`.
- [ ] **Step 4:** `go test ./internal/md/` → PASS.
- [ ] **Step 5:** Commit `feat(md): parser a modelo de bloques`.

### Task 3: Renderer a docx (`internal/render`)

**Files:** Create `internal/render/render.go`; Test `internal/render/render_test.go`

**Consumes:** `md.Block` y tipos de Task 2.
**Produces:** `func Render(blocks []md.Block, baseDir string, meta Meta) (domain.Document, error)` y `type Meta struct{ Title, Author string }`.

- [ ] **Step 1: Test que falla:** renderizar `[Heading{1,"Hola"}, Paragraph{negrita}, List, Table 2x2, CodeBlock, PageBreak]` → `doc.WriteTo(&buf)`; abrir `buf` con `archive/zip`, leer `word/document.xml`; afirmar que contiene `Heading1`, `<w:b`, el texto de la tabla (`<w:tbl>`), y que todas las partes del zip parsean con `encoding/xml`. Segundo test: `Image` con ruta inexistente → error que contiene la ruta. Tercer test: `Paragraph` con `a < b & c é 😀` → `document.xml` contiene `a &lt; b &amp; c é 😀`.
- [ ] **Step 2:** `go test ./internal/render/` → FAIL.
- [ ] **Step 3: Implementar** con la API dominio de docxgo (`docx.NewDocument()`, `doc.AddParagraph()` → `p.SetStyle(domain.StyleIDHeading1)`, `p.AddRun()` → `r.SetText/SetBold/SetItalic/SetFont`, `p.AddHyperlink(url, text)`, `doc.AddTable(rows, cols)` → `tbl.Row(i).Cell(j).AddParagraph()`, `p.AddImage(path)`, `doc.AddPageBreak()`, `doc.SetMetadata`). Código: run con fuente `Consolas` (monospace) y estilo `Normal`. Cita: estilo `Quote`. Listas: `ListParagraph` + `SetIndentLeft(720*(nivel+1))` + prefijo `• ` o `N. ` (contador por lista). Tabla: columnas = max celdas de cualquier fila; celdas faltantes vacías; primera fila en negrita. Rutas de imagen relativas se resuelven contra `baseDir`; si `os.Stat` falla → `fmt.Errorf("imagen no encontrada: %s", ruta)` antes de tocar docxgo. Si la API difiere de lo anterior, ajustar leyendo `domain/*.go` de docxgo; no cambiar el modelo.
- [ ] **Step 4:** `go test ./internal/render/` → PASS.
